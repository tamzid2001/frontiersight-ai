# Reviewed Create Lab milestone — November 12, 2026

This feature branch preserves and extends the public unified-editor work that had
not reached main. It is a working software milestone, not completion of the full
robotics product specification. Main remains `6fd1e5e9f0c9e483a6c53f1515ad5a4f6ae24b52`.

## Implemented and reviewed

- One canonical v2 scene document, monotonic revision/tenant epochs, transactional
  undo/redo, bounded recoverable history, selection and one timeline across views.
- Existing 2D tools remain explicit migration inputs; video, assumed 3D scenes,
  comparisons and editor project persistence share the existing backend services.
- A compact vertical tool dock, camera/transform controls, responsive first-run
  sample/import → inspection → intervention → proof flow and local draft export.
- Server-recomputed comparison and project evidence endpoints and MCP operations.
  Evidence records scene hashes, caller-supplied document context and unsigned
  integrity status; it confers neither measurement authenticity nor authority.
- Original illustrative warehouse/person/vehicle meshes normalized to declared
  bounds. Collision geometry and computation remain authoritative in Python.
- A review-found regression fix clamps the playhead after a shorter scene edit,
  undo/redo or recovery. Camera/view changes do not change scene geometry.

Three.js TransformControls matches the official r160 source byte for byte
(SHA256 `487861c18e017a6c69cc302827c6f506993f05dafce220da0bad095d6fe5808d`).
The existing bundled Three MIT license remains included. No private repository
source, runtime credentials, model weights or third-party scene assets were added.
