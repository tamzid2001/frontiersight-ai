# MCP integration

The current contract and examples are in [WORKBENCH_API.md](WORKBENCH_API.md).

The server exposes 54 tools. Twenty-two deterministic analysis/3D tools are available offline;
32 workbench tools share the authenticated REST dispatcher. Model invocations need
Researcher access and durable idempotency. Keys and billing remain interactive
account operations. No physical robot actuation or evidence-approval bypass.
