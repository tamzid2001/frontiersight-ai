# FrontierSight AI logo

Original vector artwork (MIT, part of this repo) — drawn programmatically,
not generated imagery, so it stays exact at every size.

| File | Use |
|---|---|
| `logo-mark.svg` | The mark alone (sight + motion trail + verified check). App icons, avatars, social. |
| `logo.svg` | Lockup for light backgrounds (dark wordmark). |
| `logo-light.svg` | Lockup for dark backgrounds (white wordmark). |
| `logo-mark-512.png` / `logo-mark-192.png` | Raster mark, transparent background. |
| `logo-1024.png` | Raster lockup (light-background variant), transparent. |
| `favicon-32.png` | Browser favicon fallback. |

Meaning: a sight/crosshair (seeing the physical world), a three-dot motion
trail leading into the tracked object at centre, and a verification check —
"models propose, geometry decides". Gradient: `#38C6D9 → #2DD4A8` on the mark;
ink `#06303E`; wordmark accent `#0A7E96`.
