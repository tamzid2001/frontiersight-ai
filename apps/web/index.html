How it works

⌖

1 · Observe

SAM 3.1 segments and tracks people, forklifts, robots in video. Muse Spark proposes what to look for — it never invents a detection.

✓

2 · Verify

Closest-approach, time-to-collision, continuity and constraint checks run in a seeded, reproducible engine. Uncalibrated video stays in pixel space — no fake metres.

⇄

3 · Counterfact

“What if the forklift had slowed 1s earlier?” A deterministic braking simulation reruns the world, Monte-Carlo intervals included, and an independent verifier checks the result.

    Getting started (2 minutes)

    1. Watch or run the demo. Overview → Run the warehouse near-miss demo, or open the Video Studio and press Run analysis. Events appear on the right; click one and the player seeks to it.
    2. Make your own world. Create Lab loads with a near-miss template. Drag waypoints, change speeds, then Run analysis. Or describe a scene in words and let Muse Spark design it.
    3. Ask “what if?”. In Counterfactual, pick the agent that should have braked, drag the intervention sliders or a preset, and read the per-actor results — including when braking helps one actor and hurts another (that happens, and the tool shows it rather than hiding it).

    No account or key is needed for any of this. Live Meta features light up automatically when the deployment has a key configured (see the badge in the top bar).

    Create Lab & path editing

    • Add a component (forklift, pedestrian, robot, vehicle, cyclist, static shelf) — it appears on the stage selected. Use Move objects to drag its body and complete path, or switch to Edit paths to lay out waypoints. Choose straight lines or smooth curve per component (curves are Catmull-Rom splines driven at constant, physically-limited speed — objects slow for tight turns and brake to a stop, just like the analysis assumes).
    • In Edit paths, click any path to select its component. Then: click near the line to insert a point exactly there, click empty stage to append, drag points to reshape, Shift-drag a path to move it whole, right-click or double-click a point to delete it, Delete/Backspace removes the last point. Hovering a path shows a pointer — paths are meant to be grabbed.
    • Path modes: stop (ends and holds), loop (patrol), ping-pong (back and forth). Amber warnings flag turns tighter than the vehicle can physically make, paths leaving the stage, or routes through a shelf — fix them by widening the curve.
    • 2D/3D: both views edit and preview the same scene on the same clock; 3D adds orbit and object dragging and destination placement in Move objects mode. Edit individual waypoints in 2D. Your per-section view choice is remembered.
    • Generate with Muse: describe the scene (up to 4,000 characters). Muse returns components, curved paths and speeds that are schema-validated and then scored by the engine (interaction quality, shelf collisions, turn warnings) — a poor first draft is retried once with the exact issues fed back. The scene is auto-labelled; press Save workspace to keep it. It also appears in the Video Studio dropdown under My workspaces.
    • Workspaces: save labs and SAM frame sets, then search, open, update, rename or delete them from Workspace (⋯ menu on each card). Guests keep them in this browser; signed-in users sync to the server.

    Analysis explained (honestly)

    • Measured numbers are sampled along the actual (curved) trajectories at 50 ms — closest distance, contact, when it happened. Predicted CPA/TTC is a constant-velocity extrapolation shown next to it. An LLM never produces these numbers.
    • Calibration rule: without a declared scale, results stay in pixels and the tool refuses metric claims rather than inventing metres. Create Lab scenes are in metres by construction.
    • Counterfactuals replay paths with a braking agent (path-following simulation + Monte-Carlo intervals). They are conditional predictions under listed assumptions — not safety certifications, and every evidence packet says so.
    • Evidence export requires a named human's approval of that exact run (Evidence view). The approval is recorded inside the exported packet; the hash chain makes tampering detectable.

    API & MCP

    The deterministic engine is exposed two ways:

    • REST: the same endpoints the UI uses (see Settings for the live /api/me, scenarios, analysis, counterfactual, SAM and billing surfaces).
    • MCP server: POST /api/mcp — connect Claude Code in one line: claude mcp add --transport http frontiersight https://frontiersight-ai.vercel.app/api/mcp, or run it offline from a clone: python3 scripts/mcp_stdio.py. Eight deterministic tools (scenarios, measured analysis, path-following counterfactuals, curve sampling, scene validation). By design, no MCP tool spends Meta credits or bypasses the human approval gate. Full guide: docs/MCP.md in the repository.

    Troubleshooting

    • Analysis seems stuck: live runs include a Muse call and can take 5–25 s (the button shows an elapsed timer). Past ~95 s the UI aborts with a named error — press Run again.
    • “SAM returned zero matches”: a valid result, shown as-is. Try a clearer concept (one short noun phrase, e.g. “forklift”), a sharper frame, or the default example frame.
    • Export is locked: evidence downloads unlock only after a named human approves that run in the Evidence view — by design.
    • 3D won’t open: your browser/GPU declined WebGL; the app returns to 2D with your scene untouched. Nothing depends on 3D.
    • My workspace is gone: guest workspaces live in this browser (clearing site data deletes them). Sign in to keep them on the server.
    • The timer looks wrong: playback is true delta-time (0.5×/1×/2× are exact); if a scene is longer than the scrub range, open it via Workspace so the range rescales.
